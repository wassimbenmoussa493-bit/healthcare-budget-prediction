# Healthcare Budget Overrun Prediction

## 1. Project Overview

This project aims to predict future healthcare expenses using historical spending data and Linear Regression.

The objective is to help healthcare insurance managers anticipate potential budget overruns and improve budget planning.

## 2. Project Objectives

* Analyze historical healthcare expenses.
* Develop a Linear Regression model.
* Predict healthcare expenses for the next three months.
* Evaluate model performance using MAE and RMSE.
* Visualize actual and predicted expenses.

## 3. Technologies
